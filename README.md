# Casino Bonus Scraper & Dashboard Task

A robust, production-ready implementation for a web developer screening task. This application scrapes online casino bonus data using Python and BeautifulSoup, structures it intelligently using the Google Gemini API with multi-tier retry logic and fallback mechanisms, and renders the results on a mobile-responsive front-end dashboard.

## Project Structure
- `scraper.py`: Python web scraper and LLM structuring script with automatic network retries and model fallbacks.
- `index.html`: Responsive front-end dashboard that dynamically parses and displays `casinos.json`.
- `casinos.json`: Structured output dataset generated by the scraper.
- `requirements.txt`: Project dependencies.

---

## Getting Started Locally

### Step 1: Clone & Set Up the Virtual Environment
Open your terminal in the project directory and create/activate your virtual environment:

**Windows (PowerShell):**
```powershell
py -m venv venv
.\venv\Scripts\Activate
```

**Linux / macOS (Bash):**
```bash
python3 -m venv venv
source venv/bin/activate
```

---

### Step 2: Install Dependencies
Install the required Python packages (requests, beautifulsoup4, google-genai):
```bash
pip install -r requirements.txt
```

---

### Step 3: Set Your Gemini API Key
To protect credentials and avoid hardcoding secrets, set your API key as an environment variable in your terminal session:

**Windows (PowerShell):**
```powershell
$env:GEMINI_API_KEY="your_key"
```

**Linux / macOS (Bash):**
```bash
export GEMINI_API_KEY="your_key"
```

---

### Step 4: Run the Scraper
Execute the scraper script to fetch and structure casino bonus data:
```bash
py scraper.py
```

---

### Step 5: Launch the Front-End Dashboard
Start a local static server to view your dashboard after scraper ``Success! Generated casinos.json with 3 casino entries``:
```bash
py -m http.server 8000
```
Then, Open your web browser and navigate to http://localhost:8000 to view the live dashboard.

## Scaling Architecture (200+ Casinos Daily)

If this pipeline were expanded to monitor over 200 casino sites daily at scale, the following production architecture would be implemented:

- **Execution Environment:** Containerized worker jobs or serverless scheduled functions via **AWS ECS (Fargate)** or **Render Cron Jobs** to ensure isolated, reliable daily execution.
- **Database & Persistence:** Transition from static JSON storage to a managed relational database like **PostgreSQL** (via AWS RDS or Supabase) with automated daily backups and historical audit tables to track bonus fluctuations over time.
- **Infrastructure & Security:** Manage DNS and SSL securely through **Cloudflare** with automated certificate renewal and DDoS protection.
- **Monitoring & Alerting:** Schedule jobs via **AWS EventBridge / Cron**, and integrate Sentry or Slack webhooks to alert the engineering team instantly if a scraper encounters schema breaks or rate-limiting.
- **Estimated Monthly Cost:** Approximately **$30 – $50 / month**, covering serverless compute, managed database storage, and proxy bandwidth.

## Project Reflection & AI Usage Summary

- **AI Tools Utilized:** Claude / Gemini coding assistants for boilerplate generation, architectural guidance, and debugging.
- **Primary Hurdles Encountered:** Frequent `503 UNAVAILABLE` cloud capacity spikes on the Gemini API endpoints and target site bot-detection blocks during initial fetches.
- **Resolution Strategy:** Implemented robust network exception handling, user-agent header masking, a multi-model fallback rotation matrix (giving each model multiple attempts), and a smart local fallback generator to guarantee operational resilience.
- **Total Time Spent:** 2 hours and 48 minutes (successfully completed within the 3-hour window).

## Technical Highlights
- **Resilient Architecture:** Incorporates multi-model fallback routines (`gemini-3.8-flash`, `gemini-3.6-flash`, etc.) with multiple retry loops to handle cloud capacity spikes (`503` errors) seamlessly.
- **Secure Handling:** Uses environment variables for API keys instead of hardcoding.
- **Fail-Safe Output: Includes a guaranteed local data fallback structure to ensure casinos.json is always successfully generated.
